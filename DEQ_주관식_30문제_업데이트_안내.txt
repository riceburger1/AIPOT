DEQ 주관식 30문제 도전 — 106문제 문제은행 업데이트
====================================================

[업데이트 내용]
• 새 메뉴: 'DEQ 주관식 30문제'
• 출제자료: 첨부 '주관식 문제.hwp'에 수록된 1~106번 문항(6개 분류)
• 세트당 30문제 / 106문제 전체에서 이전에 출제되지 않은 문제 우선 선택
• 정답 직접 입력 / 띄어쓰기·대소문자·일부 영문/약어 변형 허용
• 오답 시 한국어 초성 힌트 표시, 정답 수정 재입력 가능
• '정답 보기' 선택 시 오답으로 기록되며 다음 문제로 이동 가능
• '동일 문제 재도전', '오답만 재도전', '새로운 30문제 도전'
• 브라우저 localStorage로 문제 진행 기록을 기기에 보존
• 기존 AI-POT 1~7회차, DEQ 16챕터, DEQ 매일퀴즈 35문제, PDF 샘플 20문제,
  AI-POT 400문제 실전 모의고사, 프롬프트 구분퀴즈 유지

[검증 및 주의]
• 모든 106문항의 번호, 정답 기입 여부, 고유 ID 검증.
• JavaScript 문법 검사 및 브라우저 동작 시험(30문제 출제, 오답·초성,
  정답 공개, 다음 문제, 새 세트, 기존 퀴즈 탭 이동) 통과.
• 정답표의 일부 항목에 원본 문항 표현/정답 적합성 확인이 필요하여
  '원본 대조 필요' 안내를 유지했습니다.
• 공식 KPC 기출문제를 뜻하는 것이 아니고, 제공된 학습자료의 문항을 사용한 연습모드입니다.
• GitHub 업로드 및 실제 배포는 본 ZIP 제작만으로 자동 실행되지 않습니다.
